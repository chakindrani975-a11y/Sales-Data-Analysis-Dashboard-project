# Used Car Sales Analysis & Dashboard

## Project Overview

This project analyzes used car sales data to identify trends in sales, revenue, pricing, vehicle characteristics, and regional performance.

The project uses **Python, Pandas, SQL, and Power BI** to clean, analyze, and visualize the data.

## Objectives

- Analyze total sales and revenue
- Understand selling price trends
- Compare vehicle makes and models
- Analyze vehicle age and condition
- Compare selling price with MMR
- Identify high-performing states
- Analyze sales by vehicle body and transmission
- Build an interactive Power BI dashboard

## Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- MySQL
- SQL
- Power BI
- Excel
- GitHub
